# Кото — массивы по полочкам

Интерактивный сайт на русском по §3–6 пособия «Информатика. 10 класс» (В. М. Котов, А. И. Лапо, Ю. А. Быкадоров, Е. Н. Войтехович; Минск: Народная асвета, 2020).

Внутри: 4 урока, интерактивные массивы, пошаговые алгоритмы и программы Pascal, 4 мини-проверки и 8 задач с 40 проверочными тестами. Маскот Кото даёт объяснения и подсказки. Уроки и задания написаны самостоятельно по темам пособия; PDF не распространяется с сайтом.

## Публикация через GitHub Pages

1. Создай репозиторий GitHub и загрузи **содержимое этой папки**, сохраняя структуру. В корне должны оказаться `package.json`, `dist/` и `.github/` (не добавляй лишнюю внешнюю папку).
2. В репозитории открой **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Если основная ветка называется иначе, чем `main`, укажи её в `.github/workflows/pages.yml`.
4. Сделай push в `main` либо запусти **Actions → Publish Koto to GitHub Pages → Run workflow**. Сначала пройдут тесты, затем сайт опубликуется.
5. Адрес появится в результате шага Deploy и в Settings → Pages. Обычно это `https://USERNAME.github.io/REPOSITORY/`.

Все ссылки на скрипты, стили и Worker относительные — сайт работает и в подпапке репозитория. Секреты, API-ключи, сервер приложений и npm-зависимости не требуются. Доступность Pages для закрытого репозитория зависит от тарифа GitHub; для учебного публичного репозитория достаточно стандартного Pages.

Альтернатива без Actions: размести содержимое `dist/` в корне отдельной ветки и выбери эту ветку, каталог `/ (root)` в настройках Pages.

## Локальный запуск

Нужен Node.js 22+.

```text
npm start
```

Открой `http://127.0.0.1:4173`. Двойной щелчок по HTML не запускает ES-модули и Web Worker из-за браузерных ограничений для `file://`.

## Проверка

```text
npm test
```

Задачи проверяются реальным исполнением введённой программы в собственном учебном интерпретаторе Pascal в Web Worker. Вывод сравнивается по значениям, лишние пробелы и переводы строк игнорируются. Для каждого теста можно увидеть вход, ожидаемый и фактический результат. Проверка на конечном наборе тестов помогает найти ошибки, но не является доказательством для всех возможных входных данных.

Поддерживаются объявление переменных и статических массивов, константы, `read/readln/write/writeln`, присваивание, арифметика, сравнения, `if`, `for`, `while`, `repeat`, `begin/end`, основные числовые функции и `for var` из PascalABC.NET. Ввод трактуется как поток значений; пробелы и переводы строк равнозначны. Полный компилятор PascalABC.NET, модули GraphABC, пользовательские процедуры и функции не включены. Целые числа вычисляются в числовом диапазоне JavaScript; задачи используют небольшие значения. Есть ограничения шагов, размера массива, вывода и времени Worker. Код пользователя не передаётся в `eval` и не отправляется на сервер.

Прогресс и черновики сохраняются в `localStorage` на текущем устройстве и для текущего адреса сайта. Кнопка «По учебнику» позволяет скачать прогресс в JSON. Автоматической синхронизации между устройствами нет. Маскот использует подготовленные подсказки и результаты тестов, внешняя ИИ-модель не вызывается.

## Файлы

- `dist/index.html`, `style.css`, `app.js` — интерфейс, SVG-маскот и логика обучения.
- `dist/lessons.js` — материал, задачи, эталонные решения и тестовые данные.
- `dist/pascal.js`, `runner.js` — интерпретатор и запуск проверки в Worker.
- `tests/` — проверки интерпретатора и программ курса.
- `.github/workflows/pages.yml` — публикация GitHub Pages после проверки тестов.

Основной шрифт Golos Text загружается из Google Fonts; при отсутствии сети используется системный шрифт. Других внешних ресурсов для работы уроков и проверки кода не требуется.
